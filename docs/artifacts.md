## Локальные материалы вне Git

Эти папки существуют внутри проекта, но исключены правилами [gitignore](../.gitignore). При обычном клонировании репозитория они не появятся.

| Папка | Содержимое | Объём на дату проверки |
| --- | --- | --- |
| `output/playwright/samocvet-vk-2026-10-12/` | Рабочие копии выгрузки ВК; весь набор теперь сохранён в Git в `sources/vk/2026-10-12/` | 34 файла, около 4,0 МиБ |
| `.playwright-cli/` | Автоматические снимки страниц и консольные журналы браузерного исследования | 32 файла, около 0,5 МиБ |

Главные исходные выгрузки — [archive-posts-verified.json](../sources/vk/2026-10-12/archive-posts-verified.json) и [archive-conditions-verified.json](../sources/vk/2026-10-12/archive-conditions-verified.json). Выводы из них представлены в документах ВК. Исследование доступно после клонирования вместе с manifest; отдельного копирования игнорируемой папки не требуется. Автоматические журналы `.playwright-cli/` остаются локальными вспомогательными файлами.

## Временные копии вне проекта

В `/private/tmp/samocvet-review-20261013/` остаются исходные копии замечаний и снимков проверки. Они сохранены для старых ссылок в переписке. Рабочий документ теперь [docs/design-review.md](design-review.md), все уникальные изображения доступны в Git. Четыре повторных экспорта не дублируются в репозитории.

На дату проверки других документов в этой временной папке нет. Реестр охватывает текущий проект и известную папку его проверки; это не поиск по всем временным каталогам компьютера.
