# Самоцвет — сайт семейной школы

Многостраничный сайт семейной школы с информацией о подходе, занятиях, событиях и условиях участия.

## Возможности

- Адаптивные страницы на Astro и TypeScript.
- Общие компоненты, локальные шрифты и изображения.
- Типизированная модель контента и автоматическая статическая сборка.

## Инженерные акценты

- Разработка многостраничного сайта по графическому источнику.
- Контентная архитектура и единый визуальный язык.
- Адаптивность, статическая генерация и автоматизация публикации.

## Стек

Astro, TypeScript.

## Навигация по коду

- [src/](src/) — исходный код.
- [tests/](tests/) — автоматизированные проверки.
- [docs/](docs/) — архитектура и документация.

## Разработка

Инструменты: Node.js 24.18.0, pnpm@11.15.1.

```sh
pnpm install
pnpm dev
pnpm check
pnpm test
pnpm build
```
