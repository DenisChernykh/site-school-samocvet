# Сайт семейной школы Самоцвет

Инициативное предложение нового сайта для «Самоцвета» за 5 000 ₽. Сначала готовится демонстрационная версия, чтобы показать школе, как её подход, занятия и условия участия можно представить понятнее. Заказ на сайт со стороны школы пока не подтверждён. Планируется многостраничник, сопоставимый по устройству с `site-coach-yuliya`, с афишей.

- [Информация о проекте](docs/project-brief.md) — исходные данные, источники, визуальное направление и вопросы.
- [Черновик технического задания](docs/technical-spec.md) — предлагаемая структура, функции и условия переноса.
- [Материалы из VK](docs/vk-research.md) — подход, набор, команда, контакты, поступление, занятия, события и источники фотографий; просмотр через Playwright 12 октября 2026 года.
- [Цены и условия из старых постов VK](docs/vk-archive-prices.md) — найденные суммы с датами и ссылками; результат поиска тарифов на классы, продлёнку и индивидуальные занятия.
- [Карта контента будущего сайта](docs/content-map.md) — какие материалы подходят для каждой страницы и что остаётся уточнить у школы.

Документы дополняются по мере поступления материалов. Решения инициатора отделены от будущего согласования со школой. Целевая платформа, состав поставки за предложенную цену, условия размещения и сроки ещё не определены.

## Макет в pen.dev

[samocvet.pen](samocvet.pen) — редактируемый макет, созданный через MCP pen.dev на основе [Fieldnote](https://store.squarekicker.com/templates/fieldnote). В файле есть снимки референса, палитра, типографика и общие компоненты.

Подготовлены 11 шаблонов страниц для компьютера (1440 px) и телефона (390 px): главная, о школе, направления, подготовка к школе, знакомство и поступление, афиша, архивное событие, контакты, команда, жизнь школы, сведения и документы. Отдельно показаны мобильное меню, подтверждение формы, ошибка контакта и страница 404 — всего 26 экранов.

Главную можно посмотреть через экспорты pen.dev: [компьютер](samocvet-desktop.html), [телефон](samocvet-mobile.html). Это статические макеты; формы в экспортированных файлах не отправляют обращения. PNG находятся в `design/exports/`.

Фотографии взяты с действующего сайта школы; исходные адреса сохранены в `design/assets/sources.json`. Новые фотографии и иллюстрации для макета не генерировались. Дополнительные блоки продолжают композиции и оформление Fieldnote.

Тексты предназначены для демонстрации школе. Для афиши показаны отсутствие опубликованных ближайших встреч и архивный анонс 11 октября; год анонса требует подтверждения. Архивная цена мастер-класса не является текущим тарифом. Перед публикацией нужно подтвердить роли педагогов, условия программ, контакты, документы и содержание форм.
